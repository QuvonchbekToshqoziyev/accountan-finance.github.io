# accountan-finance.github.io

## Project Structure

- `index.html`, `login.html`, `profile.html`, and the other `.html` files stay at the repo root as page entry points.
- `assets/css/` contains shared stylesheets.
- `assets/js/` contains all JavaScript modules and page scripts.
- `assets/img/` contains the logo and favicon assets.

This keeps shared assets in one place and makes the root easier to scan.
